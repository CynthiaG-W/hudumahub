# HudumaHub

HudumaHub is a web application designed to help users find essential services around them.

## Project Overview

The application will allow users to search for nearby essential services such as:

- Hospitals
- Pharmacies
- Police stations
- ATMs
- Petrol stations
- Other essential services

The project will initially be built using React and external APIs, and later extended with a Flask backend, database, and user authentication.

## Technologies

- React
- JavaScript
- HTML
- CSS
- OpenStreetMap APIs
- Flask
- SQLAlchemy
